33 用二进制怎么表示

1、除 2 取余法

- 33 ÷ 2 = 16 余 **1** → 最低位 = 1
    
- 16 ÷ 2 = 8 余 **0** → 次低位 = 0
    
- 8 ÷ 2 = 4 余 **0** → 再次低位 = 0
    
- 4 ÷ 2 = 2 余 **0** →
    
- 2 ÷ 2 = 1 余 **0** →
    
- 1 ÷ 2 = 0 余 **1** → 最高位 = 1
    

把余数从下往上写：

`33 (十进制) = 100001 (二进制)`


2、 验证

二进制 `100001` =

`1 × 2⁵ + 0 × 2⁴ + 0 × 2³ + 0 × 2² + 0 × 2¹ + 1 × 2⁰   = 32 + 0 + 0 + 0 + 0 + 1   = 33`
