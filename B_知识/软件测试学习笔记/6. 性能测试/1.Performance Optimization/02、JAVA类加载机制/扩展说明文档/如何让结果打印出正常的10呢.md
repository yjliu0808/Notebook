
### 方案 A：调换静态成员的声明顺序（最简单、最直观）

```java
class Apple{
    static double price = 20.00;          // 先初始化 price
    static Apple apple = new Apple(10);   // 再创建 apple
    double totalpay;

    public Apple (double discount) {
        System.out.println("===="+price); // 此时为 20.0
        totalpay = price - discount;      // 20 - 10 = 10
    }
}
public class PriceTest01 {
    public static void main(String[] args) {
        System.out.println(Apple.apple.totalpay); // 输出 10.0
    }
}

```

### 方案 B：用静态初始化块，明确初始化顺序

```java
class Apple{
    static double price;
    static Apple apple;
    double totalpay;

    static {
        price = 20.00;             // 先设 price
        apple = new Apple(10);     // 再 new Apple
    }

    public Apple (double discount) {
        System.out.println("===="+price);
        totalpay = price - discount;
    }
}

```

### 方案 C：延迟创建 `apple`（懒加载）
```java
class Apple{
    static double price = 20.00;
    private static Apple apple;    // 先不创建

    double totalpay;

    public static Apple getApple() {
        if (apple == null) {
            apple = new Apple(10); // 使用时再创建，此时 price 已就绪
        }
        return apple;
    }

    public Apple (double discount) {
        System.out.println("===="+price);
        totalpay = price - discount;
    }
}
public class PriceTest01 {
    public static void main(String[] args) {
        System.out.println(Apple.getApple().totalpay); // 10.0
    }
}

```


### 方案 D：把计算放到构造之后的显式方法里（避免在半初始化期做计算）
```java
class Apple{
    static double price = 20.00;
    double totalpay;

    public Apple (double discount) {
        // 构造时先不算
    }
    public void calc(double discount){
        System.out.println("===="+price);
        totalpay = price - discount;
    }
}
public class PriceTest01 {
    public static void main(String[] args) {
        Apple a = new Apple(10);
        a.calc(10);                       // 这时 price 已是 20.0
        System.out.println(a.totalpay);   // 10.0
    }
}

```


❗补充说明：

- 仅仅尝试“先访问 `Apple.price`”并不能改变类初始化里“按源码顺序执行静态赋值”的事实；只要类被初始化，就会先跑 `apple = new Apple(10)` 再跑 `price = 20.00`（按原代码顺序），问题依旧。
    
- 因此必须显式改变执行顺序或把计算推迟到 `price` 就绪之后。
