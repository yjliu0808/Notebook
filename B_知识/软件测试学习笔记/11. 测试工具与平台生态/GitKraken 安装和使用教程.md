### **GitKraken 安装和使用教程**

------

### **步骤 1：下载和安装 GitKraken**

1. **访问官网**
    打开浏览器，访问 GitKraken 官方网站：[GitKraken 下载页面](https://www.gitkraken.com/download)
2. **选择操作系统**
    根据你所使用的操作系统（Windows、macOS 或 Linux），选择合适的版本下载：
   - **Windows**：下载 `.exe` 安装文件。
   - **macOS**：下载 `.dmg` 安装文件。
   - **Linux**：根据发行版选择 `.deb` 或 `.rpm` 文件。
3. **安装 GitKraken**
    根据你的操作系统，执行安装过程：
   - 在 Windows 上，双击 `.exe` 文件并按照向导步骤进行安装。
   - 在 macOS 上，双击 `.dmg` 文件并将 GitKraken 拖动到 **应用程序** 文件夹。
   - 在 Linux 上，使用 `dpkg` 或 `rpm` 安装文件来安装。
4. **启动 GitKraken**
    安装完成后，启动 GitKraken。如果是第一次启动，可能会提示你注册或登录一个账户，可以选择创建一个账户（对于 GitKraken Cloud 功能）或者跳过。

------

### **步骤 2：创建 Git 仓库 (或者克隆现有仓库)**

1. **创建新仓库**：
   - 打开 GitKraken 后，点击左上角的 **"File"** 菜单，选择 **"Create a new repository"**。
   - 选择一个目录来创建本地 Git 仓库，设置仓库名称和路径。
   - 选择仓库初始化选项（如是否添加 `.gitignore` 文件等），然后点击 **"Create"**。
2. **克隆现有仓库**：
   - 如果你已经有一个远程 Git 仓库，点击 **"Clone a repository"** 按钮。
   - 输入远程仓库的 URL（比如 GitHub 或 GitLab 上的仓库地址），并选择本地路径来存储克隆的仓库。
   - 点击 **"Clone"**，GitKraken 会将仓库克隆到本地。

------

### **步骤 3：添加/修改文件**

1. **在 GitKraken 中编辑文件**：

   - 你可以直接在文件管理器中添加或修改文件，GitKraken 会自动检测文件的变化。

   - 例如，创建一个 `README.md` 文件并添加内容：

     ```
     # 项目名称
     这是一个简单的 Git 项目，用于展示 GitKraken 的使用。
     
     ## 安装
     使用以下命令安装依赖：
     ```bash
     npm install
     ```

     ## 使用

     请遵循以下步骤运行该项目：

     1. 克隆仓库
     2. 运行 `npm start`

     ```
     
     ```

2. **保存文件**：保存你所做的修改。

------

### **步骤 4：提交更改 (Commit)**

1. **查看更改**：
   - 在 GitKraken 中，你可以在左侧的 **"Commit"** 区域看到你所做的文件更改。GitKraken 会显示你修改过的文件，并在文件旁边显示变动的行。
2. **选择要提交的文件**：
   - 在左侧 **"Unstaged Files"** 区域，选择你想要提交的文件，右键点击并选择 **"Stage"** 来将它们添加到暂存区。
3. **填写提交信息**：
   - 在底部的 **"Commit Message"** 区域，填写提交信息（例如：`Add initial README.md`）。
   - 然后点击 **"Commit Changes"** 按钮来提交这些更改。

------

### **步骤 5：推送更改到远程仓库**

1. **推送更改**：
   - 如果你的仓库与远程仓库已连接，点击顶部的 **"Push"** 按钮，将你的提交推送到远程仓库。
   - 如果是首次推送，GitKraken 会提示你输入远程仓库的 URL 和认证信息。

------

### **步骤 6：查看提交历史和差异**

1. **查看提交历史**：
   - 在 GitKraken 的中央面板，你可以查看项目的提交历史。每个提交都有一个提交信息、时间戳和作者。
   - 点击某个提交，可以查看该提交的详细信息，包括修改过的文件和行级差异。
2. **查看差异**：
   - 点击某个提交，GitKraken 会在右侧面板显示该提交和之前提交之间的文件差异。红色表示删除的内容，绿色表示新增的内容。

------

### **步骤 7：生成 `README.md` 文件 (手动保存)**

你可以将生成的 `README.md` 文件保存在本地仓库目录中，或者将其内容复制到你文档中，以便后续存档。

1. **生成并保存 README.md**：
   - 打开你编辑的 `README.md` 文件，将其内容保存并保留在项目根目录。

------

### **步骤 8：推送文件和更新到远程仓库**

1. **确保一切都已提交并推送**：
   - 确保所有更改都已提交，并推送到远程仓库。

------

### **总结**

GitKraken 提供了一个非常直观的图形化界面，适合新手使用。你可以通过以下步骤完成 Git 的基本操作：

1. 安装 GitKraken。
2. 创建或克隆 Git 仓库。
3. 添加/修改文件（例如生成 `README.md` 文件）。
4. 提交更改并推送到远程仓库。
5. 查看提交历史和差异。
