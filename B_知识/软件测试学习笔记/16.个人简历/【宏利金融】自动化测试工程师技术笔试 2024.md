What’s the differences of copy and deep copy? (Only for Sr.) 

- Shallow copy: Copies the object's bitwise values. If the object contains references to other objects, only the references are copied . changes to a nested object in the origin will relect int the copy. Deep copy: Creates a completely independent clone.It recursively copies the object and all objects it references. changes to the originale have zero impact on the deep copy.
