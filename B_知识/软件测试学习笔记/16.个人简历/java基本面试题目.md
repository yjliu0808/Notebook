## **一、字符串（String）面试题**

1. 给定一个字符串 `"hello world"`，请反转字符串并输出。
    
2. 判断一个字符串是否是回文字符串（正读和反读一样）。
    
3. 统计字符串中每个字符出现的次数。
    
4. 删除字符串中的重复字符，只保留第一次出现的字符。
    
5. 找到字符串中出现次数最多的字符。
    
6. 将字符串 `"Java_is_fun"` 中的下划线 `_` 替换为空格。
    
7. 字符串 `"JavaProgramming"` 转换为 **字符数组** 并输出每个字符。
    

---

## **二、数组（Array）面试题**

1. 给定一个整数数组，找出其中的最大值和最小值。
    
2. 将数组中的元素反转输出。
    
3. 使用冒泡排序对数组进行升序排序。
    
4. 使用冒泡排序对数组进行降序排序。
    
5. 判断数组中是否有重复元素。
    
6. 找出数组中出现次数超过一半的元素（摩尔投票法面试题常考）。
    
7. 合并两个已排序的数组，输出合并后的升序数组。
    
8. 给定一个数组，将所有奇数移到前半部分，偶数移到后半部分。
    

---

## **三、List 集合（List）面试题**

1. 创建一个 List，添加 5 个水果名称，遍历输出。
    
2. 在 List 的指定索引位置插入一个元素，并打印结果。
    
3. 删除 List 中重复的元素，并保持原顺序。
    
4. 找出 List 中最大值和最小值（整数 List）。
    
5. 对 List 中的整数进行升序排序和降序排序。
    
6. 遍历 List 并统计每个元素出现的次数（适用于字符串或整数）。
    
7. 将一个数组转换为 List，并输出。
    

---

## **四、Set 集合（Set）面试题**

1. 创建一个 HashSet 并添加 5 个元素，遍历输出。
    
2. 判断 Set 中是否存在指定元素。
    
3. 给定一个 List，使用 Set 去重并输出结果。
    
4. 统计 List 中不同元素的个数（通过 Set 实现）。
    
5. 将一个 List 放入 TreeSet 并输出升序结果。
    
6. 遍历 Set 并打印其中的每个元素。
    
7. 比较两个 Set 是否有交集，输出交集元素。
