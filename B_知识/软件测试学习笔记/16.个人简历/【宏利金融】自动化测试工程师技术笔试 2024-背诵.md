## **Programming – Java**

### **第1题：Overload vs Override**

- **Overload（方法重载）**
    
    - 同一个类中，方法名相同，但参数不同（类型、数量或顺序）。
        
    - **编译时多态（Compile-time polymorphism）**
        
    - 英文解释：Same method name but different parameters. Compile-time polymorphism.
        
    - 发音：/ˈoʊvərˌloʊd/
        
- **Override（方法重写）**
    
    - 子类重新定义父类的方法，方法签名必须完全相同。
        
    - **运行时多态（Runtime polymorphism）**
        
    - 英文解释：Subclass redefines a method from its superclass. Runtime polymorphism.
        
    - 发音：/ˈoʊvərˌraɪd/
        

---

### **第2题：Static 方法中能否使用非静态变量**

- **答案**：不能直接使用。
    
- **原因**：静态方法可在不创建对象的情况下调用，而非静态变量属于类实例，编译器无法确定访问哪一个实例的变量，因此会在**编译阶段报错（Compile-time error）**。

### **第5题：求数组中出现次数最多的元素**

import java.util.*;  
  
public class FrequencyTask {  
    public static void findMostFrequent(int[] nums) {  
        if (nums == null || nums.length == 0) return;  
  
        Map<Integer, Integer> map = new HashMap<>();  
        for (int num : nums) {  
            map.put(num, map.getOrDefault(num, 0) + 1);  
        }  
  
        int maxNum = nums[0];  
        int maxCount = 0;  
  
        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {  
            if (entry.getValue() > maxCount) {  
                maxCount = entry.getValue();  
                maxNum = entry.getKey();  
            }  
        }  
  
        System.out.println("Number: " + maxNum + ", Max repetition: " + maxCount);  
    }  
}
